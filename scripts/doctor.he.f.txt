; ---- זמן: שעות, משכים, וימים -------------------------------------------
; אדם שמספר על עצמו מודד הכול בזמן. קמתי בחמש, הנסיעה לוקחת שעתיים,
; אחרי שבוע הפסקתי, כל יום אותו דבר. אלה אינם פרטים טכניים -- הם הצורה
; שבה נמסרת מצוקה, ותסריט שאין לו מה לומר עליהם מחזיר הודעת מילוט בדיוק
; ברגע שבו נמסר הדבר הקונקרטי ביותר בשיחה.
;
; -- שלוש שכבות, שלוש עדיפויות --
;
; השעה על ארבע. "בחמש" היא מילה חד-משמעית שאין לה שום שימוש אחר, והיא
; גוברת גם על מכונת העבר -- "קמתי היום בחמש וחצי" הוא משפט על השעה,
; לא על הקימה.
;
; המשך על שלוש. שעתיים, שבוע, חודש. כאן יש התנגשות אמיתית עם מכונת
; העבר, וההכרעה היא לפי מי נמצא ראשון במשפט: "אחרי שבוע התחלתי" נפתח
; בזמן ונענה על הזמן, "למדתי שלוש שעות" נפתח בפועל ונענה על הפועל.
; זה מה שהמנוע עושה מאליו עם שתי מילים באותה עדיפות, ולכן אין כאן צורך
; בשום מנגנון.
;

; "למה אתה שואל את זה?", כאילו הייתה זו שאלה על אלייזה.
;

;

; מה עומד בצד השני. שום ידיעה על העולם, ושום דבר שכלל של 1966 לא ידע
; לעשות.

; זו הצורה הרביעית והאחרונה של ההצבעה לאחור, והיא הפוכה מכולן: הדובר
; אינו מצביע על משפט שנאמר ואינו מצביע על רגע שהיה, אלא מודיע שבין אז
; לעכשיו לא קרה דבר. "אנחנו באותו מקום". "זה אותו דבר בדיוק". "נשארנו
; באותה נקודה". "לא זזנו מאז".

; -- מה שקרה עד עכשיו --
;
; "אנחנו באותו מקום" לא מצא אף מילת מפתח ונענה בהודעת מילוט, ו"לא זזנו
; מאז" נענה "למה לא?" -- שאלה שנשאלת על סירוב, והמשפט אינו סירוב אלא
; דיווח. "אותו" לבדה כן נענית, ויפה, ב"ושום דבר אינו משתנה?" -- אבל
; בלי להחזיר לדובר מילה אחת משלו, ולכן בלי לומר לו שנשמע מה שאמר.
;

; "כל יום אותו דבר" אינו נחלק לנושא ולנשוא: כולו הודעה אחת, וכל מילה בו

; במילה ואחריו נקודה. מה שנשאר אחרי הנקודה הוא שאלה אחת, ותמיד אותה
; שאלה: מה בעצם לא זז שם.

; -- ומה שנשאר בחוץ --

; "דבר" היא גם "שום דבר" ו"כל דבר" ו"דבר אחד"; ו"עומדים" היא גם אנשים

; לצירוף ולא למילה, וכל השאר יוצא ב-NEWKEY אל המילה הבאה בערימה
; כאילו לא הייתה כאן מילת מפתח כלל.
;

; הקודמת, והוא יושב גבוה יותר. "באותה" יושבת על שבע בדיוק כדי

; ---- "בהתחלה", "כאמור", "הרי": ההפניה אל מה שהאחר כבר יודע ------------
; ארבע מילים שנשארו בחוץ אחרי כל הקודמות, וכולן עושות אותו דבר: הן
; פוטרות את הדובר מלומר את הדבר שוב, משום שלדעתו הוא כבר נאמר.
;
; "ציינתי את זה בהתחלה" לא מצא אף מילת מפתח ונענה "הממ..." -- שני
; פעלים של אמירה במשפט אחד, ואף אחד מהם לא היה מוכר לתסריט. "בהתחלה
; זה היה אחרת" נקרא כמשפט על השתנות, בלי הרגע שאליו הוא מצביע.
; ו"הרי כבר אמרתי לך" נענה על "כבר", וזה מקרה טוב -- אבל "הרי אתה
; יודע את זה" לא נענה כלל.
;
; -- מה שאלייזה עושה איתן --
;
; אותו מהלך עצמו של כל הקבוצה: המשפט חוזר אל הדובר בשלמותו, ואחריו
; שאלה אחת. השאלה כאן היא זו שהמילה מזמינה -- מה השתנה מאז ההתחלה, מה
; בא לפני המסקנה, ומה בעצם אני אמורה כבר לדעת. אין כאן ידיעה, אין
; עצה, ואין דבר שכלל של 1966 לא ידע לעשות.
;
; -- ולמה "ציינתי" אינה מצטטת --
;
; מה שבא אחרי "ציינתי" נפתח כמעט תמיד ב"את" או ב"ש", ומשפט בעברית
; שנפתח באחת מהן אינו משפט. לכן הכלל הזה עונה במילותיו שלו: הוא מודיע
; שהדבר נשמע, ושואל מה מחזיר אליו. הפועל עצמו כבר עבר היפוך והוא
; "ציינת" ולא "ציינתי", ולכן גם אותו אין מה להחזיר.
;
; -- ועל הגובה --
;
; "כאמור" ו"ציינתי" על שמונה: הן כמעט ואינן נאמרות אלא לשם ההצבעה
; הזאת. "בהתחלה" ו"הרי" על שבע, כדי ש"כמו בהתחלה" ו"הרי כבר אמרתי
; לך" יישארו אצל הכללים שכבר נכתבו בשבילם. וכולן נגמרות ב-NEWKEY.
; -----------------------------------------------------------------------
